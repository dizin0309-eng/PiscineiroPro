Configuração do banco online

Esta versão está preparada para funcionar com Supabase. Antes de publicar para clientes, coloque as duas informações no arquivo supabase-config.js.

  1. Crie um projeto no Supabase.
  2. Execute o arquivo supabase-schema.sql no SQL Editor.
  3. Copie a URL e a chave pública (Publishable key) para supabase-config.js.
  4. Publique novamente esta pasta no Netlify.

A chave pública anon pode ficar no navegador quando as políticas RLS do banco estiverem configuradas corretamente. Nunca coloque uma chave secreta/service_role no site.
